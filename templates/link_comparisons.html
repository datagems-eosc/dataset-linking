Numeric values and formulas:

  • Visible numeric columns are Relation Sim., Keyword Overlap, Metric Similarity, Chunk Similarity, and the percentages shown in the shared file/table and CSV/table column columns.
  • Relation Sim. compares two DataLinkingBase links. Without description chunks it is calculated as: 65% keyword overlap + 30% file/table or CSV/table column evidence overlap + 5% shared profile score.
  • Relation Sim. with chunks, when description chunks are available, is calculated as: 70% SBERT chunk similarity + 25% keyword overlap + 5% shared profile score.
  • Keyword Overlap is a visible column. It is the Jaccard overlap between the common keywords of the two links: shared keywords divided by all distinct keywords.
  • Metric Similarity is diagnostic only and is not used in Relation Sim. It compares the numeric score profile of the two links, but numeric score similarity alone does not imply semantic coherence.
  • Shared Profile Score is used internally in Relation Sim.; it is not shown as a separate column. It is 0% when two links share no dataset/profile, 50% when they share one profile, and 100% when both profiles are shared.
  • Chunk Similarity compares the description chunk evidence of the two DataLinkingBase links with SBERT.
  • Evidence percentages are Jaccard overlaps for file/table names or CSV/table column names found in non-shared profile evidence: shared items divided by all distinct items in that evidence category.
