Numeric values and formulas:

  • Visible numeric columns are Relation Sim., Keyword Overlap, Metric Similarity, Link 1/2 Weights, and the percentages shown in the three Refinement Shared columns.
  • Relation Sim. compares two DataLinkingBase links. Without description chunks it is calculated as: 55% keyword overlap + 40% metric similarity + 5% shared profile score.
  • Relation Sim. with chunks, when description chunks are available, is calculated as: 45% keyword overlap + 35% metric similarity + 15% description chunk similarity + 5% shared profile score.
  • Keyword Overlap is a visible column. It is the Jaccard overlap between the common keywords of the two links: shared keywords divided by all distinct keywords.
  • Metric Similarity is a visible column. It compares the numeric score profile of the two links: keywords similarity, description similarity, headline similarity and combined similarity. Values are normalized to 0-1, compared with root mean square distance, then converted with 1 - distance.
  • Link 1 Weights and Link 2 Weights show the effective KW/DESC/HEAD weights used when each original DataLinkingBase link was scored.
  • Shared Profile Score is used internally in Relation Sim.; it is not shown as a separate column. It is 0% when two links share no dataset/profile, 50% when they share one profile, and 100% when both profiles are shared.
  • Description Chunk Similarity is used internally only when description chunks are available; it is not shown as a separate column.
  • Refinement percentages are shown inside the three Refinement Shared columns. They are Jaccard overlaps for files, columns or samples found in the refinement evidence: shared items divided by all distinct items in that evidence category.
